# TiendaPOSS

Sistema POS multi-tienda (SaaS) para negocios de barrio: punto de venta, caja y turnos, inventario inteligente,
proveedores y compras, pagos digitales, finanzas, analítica, alertas y asistente de IA.

- Alcance completo y estado de cada ítem: [docs/CHECKLIST.md](docs/CHECKLIST.md)
- Desarrollo local: [docs/DEV.md](docs/DEV.md)
- Estética: [design/stitch/modern_retail_pos/DESIGN.md](design/stitch/modern_retail_pos/DESIGN.md)

Stack: Java 21 + Spring Boot 3.3 + PostgreSQL (Flyway) · React 19 + Vite + Tailwind 4 (PWA).
